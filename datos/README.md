# Datos de los ejemplos

Los primeros capítulos generan muestras sintéticas con semillas fijas. Esto permite ejecutar cada ejemplo sin descargar archivos y evita presentar como observaciones reales datos cuyo origen, licencia o soporte todavía no fueron documentados.

El caso didáctico real de arsénico de la presentación se incorporará cuando estén consolidados:
Mientras tanto, `arsenico_sintetico.csv` proporciona una población didáctica completamente sintética y reproducible. No representa mediciones reales ni debe utilizarse para evaluar exposición. Se genera mediante `ejemplos/generar_caso_arsenico.py` con semilla fija.
- procedencia y licencia;
- identificadores y número definitivo de pozos;
- unidades y límites de detección;
- sistema de coordenadas;
- profundidad y soporte;
- criterio para seleccionar una observación por pozo.
