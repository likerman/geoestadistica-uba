# Ejemplos reproducibles

Cada ejemplo tendrá su propia carpeta con:

- una pregunta concreta;
- procedencia y licencia de los datos;
- diccionario de variables;
- código ejecutable;
- resultados principales;
- vínculo al capítulo que lo interpreta.

El primer ejemplo previsto es el análisis progresivo de arsénico en pozos de la provincia de Buenos Aires. Hasta verificar procedencia, licencia, unidades, coordenadas y criterio de selección, no se incorporarán datos reales a este repositorio.
